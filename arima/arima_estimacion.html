Modelos ARMA, ARIMA y Estimación

Combinando AR y MA, integración para series no estacionarias, técnica Box-Jenkins, selección automática con auto_arima y pronósticos con bootstrap en Python

Datos: Serie simulada ARIMA(0,1,1) · Repositorio del curso

1. Modelos ARMA(p,q)

Un proceso ARMA(p,q) combina ambas familias — componentes autoregresivos y de media móvil:

$$y_t = \delta + \phi_1 y_{t-1} + \cdots + \phi_p y_{t-p} + \theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q} + \varepsilon_t$$

Usando el operador de rezago $L$ (donde $Ly_t = y_{t-1}$), esto se escribe de forma compacta como:

$$\phi_p(L) \, y_t = \theta_q(L) \, \varepsilon_t$$

donde $\phi_p(L) = 1 - \phi_1 L - \cdots - \phi_p L^p$ y $\theta_q(L) = 1 + \theta_1 L + \cdots + \theta_q L^q$.

EstacionariedadRaíces de $\phi_p(z) = 0$ fuera del círculo unitario

PACF$\rho_s^* \neq 0$ para $s \leq p$, luego decae exponencialmente

2. Modelos ARIMA(p,d,q)

Muchas series económicas no son estacionarias (tienen tendencia). Si diferenciamos $d$ veces la serie y obtenemos una serie estacionaria, decimos que $y_t \sim I(d)$ (integrada de orden $d$). Un modelo ARIMA(p,d,q) aplica un ARMA(p,q) sobre la serie diferenciada:

$$\Delta^d y_t = \delta + \phi_1 \Delta^d y_{t-1} + \cdots + \phi_p \Delta^d y_{t-p} + \theta_1 \varepsilon_{t-1} + \cdots + \theta_q \varepsilon_{t-q} + \varepsilon_t$$

donde $\Delta y_t = y_t - y_{t-1}$ es el operador de primera diferencia. Casos especiales importantes:

Casos especiales

ARIMA(0,0,0) = ruido blanco. ARIMA(0,1,0) = caminata aleatoria (random walk). ARIMA(p,0,q) = ARMA(p,q). ARIMA(0,1,1) = suavización exponencial simple (conexión con los métodos del Cap. 3).

3. Estimación: Técnica de Box-Jenkins

Box y Jenkins (1976) propusieron una metodología iterativa en tres fases para estimar modelos ARIMA:

Las tres fases de Box-Jenkins

1. Identificación: Graficar la serie, determinar si es estacionaria (diferenciar si no lo es), examinar ACF y PACF muestrales para proponer candidatos ARIMA(p,d,q).

2. Estimación: Estimar los parámetros por máxima verosimilitud.

3. Diagnóstico: Verificar que los residuales sean ruido blanco (no autocorrelación, homoscedasticidad, normalidad). Si no cumplen, volver a la fase 1.

Esta técnica tiene una componente de "arte" — dos investigadores pueden llegar a modelos candidatos diferentes al examinar la misma ACF/PACF. Por eso se complementa con selección automática.

4. Implementación en Python

4.1 Carga de datos y ACF/PACF

python
from pmdarima.arima import auto_arima, ARIMA
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import pandas as pd, numpy as np
import matplotlib.pyplot as plt
import statsmodels.api as sm

# Datos simulados ARIMA(0,1,1)
data = pd.read_csv(
    "https://raw.githubusercontent.com/dagudelo30/Series-de-tiempo---Javeriana-Cali/refs/heads/main/arima/arima011.csv"
)

# ACF y PACF
fig, axes = plt.subplots(1, 2, figsize=(12, 4))
plot_acf(data['ARIMA011'], lags=40, ax=axes[0])
plot_pacf(data['ARIMA011'], lags=40, ax=axes[1])
plt.tight_layout(); plt.show()

La ACF decae lentamente (señal de no estacionariedad → necesitamos diferenciar). Tras diferenciar, la ACF se trunca en el rezago 1 → candidato MA(1), es decir ARIMA(0,1,1).

4.2 Selección automática con auto_arima

python
# auto_arima: busca el mejor modelo minimizando AIC
model = auto_arima(
    data["ARIMA011"],
    max_p=10, max_q=10,
    information_criterion="aic",
    trace=True,
    error_action='ignore',
    suppress_warnings=True
)
model.summary()

4.3 Diagnóstico de residuales

python
# Obtener residuales
residuals = model.resid()

# Gráfico de residuales
fig = plt.figure(figsize=(12, 6))
plt.plot(residuals, label="Residuales")
plt.axhline(0, color='red', ls='--')
plt.legend(); plt.show()

# Prueba Ljung-Box sobre residuales
lb_test = sm.stats.acorr_ljungbox(residuals, lags=20, return_df=True)
print(lb_test)

4.4 Pronóstico

python
h = 10
y_forec, conf_int = model.predict(h, return_conf_int=True, alpha=0.05)

preds = pd.DataFrame(
    np.column_stack([y_forec, conf_int[:, 0], conf_int[:, 1]]),
    columns=['Point_forecast', 'lower_95', 'upper_95']
)

x_for = np.linspace(data.shape[0] + 1, data.shape[0] + h, h)

fig = plt.figure(figsize=(12, 6))
plt.plot(data["time"], data["ARIMA011"], label="ARIMA011")
plt.plot(x_for, preds['Point_forecast'], label="Pronóstico")
plt.fill_between(x_for, preds['lower_95'], preds['upper_95'],
                color='blue', alpha=0.1)
plt.legend(); plt.show()

5. Intervalos de confianza con Bootstrap

Los intervalos de confianza paramétricos asumen normalidad de los errores. Si este supuesto no se cumple, se pueden construir intervalos por bootstrap: remuestrear los residuales con reemplazo y simular muchas trayectorias futuras.

python
# Ajustar modelo manualmente
model_manual = ARIMA(order=(0, 1, 1))
results = model_manual.fit(data["ARIMA011"])

h = 10
res = results.resid()

# Bootstrap: 1000 remuestreos de los residuales
my_samples = []
for _ in range(1000):
    x = np.random.choice(res, size=h, replace=True)
    my_samples.append(x)

# Cuantiles acumulados para intervalos
q1 = np.quantile(my_samples, 0.025, axis=0)
q2 = np.quantile(my_samples, 0.975, axis=0)

fore = results.predict(h, return_conf_int=False)

preds = pd.DataFrame({
    'Point_forecast': fore,
    'lower_95': fore + np.cumsum(q1),
    'upper_95': fore + np.cumsum(q2)
})
print(preds)

6. Criterios de información

Los criterios de información penalizan la complejidad del modelo para evitar sobreajuste:

AIC (Akaike): $$\text{AIC} = -2 \ln(L) + 2k$$ BIC (Bayesiano): $$\text{BIC} = -2 \ln(L) + k \ln(T)$$

donde $L$ es la verosimilitud, $k$ el número de parámetros y $T$ el tamaño de la muestra. El BIC penaliza más los parámetros adicionales y tiende a seleccionar modelos más parsimoniosos. auto_arima acepta information_criterion = "aic", "aicc", "bic" o "hqic".
