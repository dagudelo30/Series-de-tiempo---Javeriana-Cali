Modelos Autoregresivos (AR) y de Media Móvil (MA)

Las dos familias fundamentales de procesos estocásticos para series de tiempo: propiedades teóricas, simulaciones y funciones de autocorrelación en Python

Repositorio del curso

1. Modelos Autoregresivos — AR(p)

La familia AR supone que el valor actual de la serie depende linealmente de sus propios valores pasados. Un proceso AR(p) tiene la forma:

$$y_t = \delta + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \cdots + \phi_p y_{t-p} + \varepsilon_t = \delta + \sum_{i=1}^{p} \phi_i y_{t-i} + \varepsilon_t$$

donde $\delta$ es una constante, $\phi_1, \ldots, \phi_p$ son los coeficientes autoregresivos y $\varepsilon_t$ es ruido blanco.

1.1 Proceso AR(1)

El caso más simple: $y_t = \delta + \phi_1 y_{t-1} + \varepsilon_t$. Sustituyendo recursivamente, se obtiene la representación de media móvil infinita:

$$y_t = \frac{\delta}{1 - \phi_1} + \sum_{i=0}^{\infty} \phi_1^i \varepsilon_{t-i}$$

De aquí se derivan las propiedades fundamentales:

Media: $$E[y_t] = \frac{\delta}{1 - \phi_1} = \mu$$ Varianza: $$\text{Var}[y_t] = \frac{\sigma_\varepsilon^2}{1 - \phi_1^2} = \gamma_0$$ Autocovarianza al rezago s: $$\gamma_s = \phi_1^s \cdot \gamma_0$$ Autocorrelación (ACF): $$\rho_s = \phi_1^s$$
Condición de estacionariedad

El proceso AR(1) es estacionario si y solo si $|\phi_1| < 1$. Equivalentemente, la raíz del polinomio característico $1 - \phi_1 z = 0$ debe estar fuera del círculo unitario: $|z| = |1/\phi_1| > 1$. Si $|\phi_1| \geq 1$, los choques se acumulan sin límite y la serie no es estacionaria (Alonso, 2020).

Una propiedad clave es la reversión a la media (mean reverting): sin importar la magnitud de la perturbación, el proceso siempre tiende a regresar a su media $\mu$.

1.2 Simulación de procesos AR(1) en Python

python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(123)
T = 100
phis = [0.25, -0.25, 0.5, -0.5, 0.9, -0.9]
eps = np.random.normal(0, 1, T)

def sim_ar1(phi, eps):
    y = np.zeros_like(eps)
    for t in range(1, len(eps)):
        y[t] = phi * y[t-1] + eps[t]
    return y

fig, axes = plt.subplots(3, 2, figsize=(10, 8), sharex=True)
for ax, phi in zip(axes.ravel(), phis):
    y = sim_ar1(phi, eps)
    ax.plot(y, lw=0.8)
    ax.set_title(f'φ₁ = {phi}')
    ax.axhline(0, color='gray', ls='--', lw=0.5)
plt.tight_layout(); plt.show()

1.3 ACF teórica del AR(1)

La ACF del AR(1) es $\rho_s = \phi_1^s$: decae exponencialmente si $\phi_1 > 0$, y de manera oscilante si $\phi_1 < 0$.

python
max_lag = 25
fig, axes = plt.subplots(3, 2, figsize=(10, 8), sharex=True, sharey=True)
for ax, phi in zip(axes.ravel(), phis):
    lags = np.arange(0, max_lag + 1)
    acf_vals = phi ** lags   # ρ_s = φ^s
    ax.vlines(lags, 0, acf_vals, linewidth=1)
    ax.scatter(lags, acf_vals, s=10)
    ax.set_title(f'ACF teórica: φ₁ = {phi}')
    ax.axhline(0, color='black', lw=0.5)
plt.tight_layout(); plt.show()

1.4 Proceso AR(2)

Un AR(2) tiene la forma $y_t = \delta + \phi_1 y_{t-1} + \phi_2 y_{t-2} + \varepsilon_t$. La condición de estacionariedad requiere que ambas raíces del polinomio característico $1 - \phi_1 z - \phi_2 z^2 = 0$ estén fuera del círculo unitario. Una condición necesaria (pero no suficiente) es $\phi_1 + \phi_2 < 1$.

2. Modelos de Media Móvil — MA(q)

La familia MA supone que el valor actual depende linealmente de los errores pasados (no de los valores pasados de la serie). Un proceso MA(q) tiene la forma:

$$y_t = \delta + \theta_1 \varepsilon_{t-1} + \theta_2 \varepsilon_{t-2} + \cdots + \theta_q \varepsilon_{t-q} + \varepsilon_t = \delta + \sum_{i=1}^{q} \theta_i \varepsilon_{t-i} + \varepsilon_t$$

2.1 Proceso MA(1)

El MA(1): $y_t = \delta + \theta_1 \varepsilon_{t-1} + \varepsilon_t$. Sus propiedades:

Media: $$E[y_t] = \delta = \mu$$ Varianza: $$\gamma_0 = \sigma_\varepsilon^2(1 + \theta_1^2)$$ ACF: $$\rho_s = \begin{cases} 1 & s = 0 \\ \frac{\theta_1}{1 + \theta_1^2} & s = 1 \\ 0 & s \geq 2 \end{cases}$$
MA siempre estacionario

Todo proceso MA(q) es estacionario, sin importar los valores de $\theta_1, \ldots, \theta_q$. No se necesita ninguna restricción sobre los parámetros. Esto contrasta con los AR, donde sí hay condiciones de estacionariedad.

La propiedad distintiva de un MA(q) es que su ACF se trunca después del rezago $q$: es exactamente cero para $s > q$. Esto permite identificar el orden $q$ observando la ACF muestral.

3. ACF vs PACF: Identificación de modelos

La función de autocorrelación parcial (PACF) mide la correlación entre $y_t$ y $y_{t-s}$ después de eliminar el efecto de los rezagos intermedios. Es equivalente al coeficiente $\phi_s^{(s)}$ en la regresión:

$$y_t - \mu = \phi_1^{(s)}(y_{t-1} - \mu) + \phi_2^{(s)}(y_{t-2} - \mu) + \cdots + \phi_s^{(s)}(y_{t-s} - \mu)$$
ProcesoACFPACF
AR(p)Decae exponencialmente (o de forma oscilante)Se trunca después del rezago p
MA(q)Se trunca después del rezago qDecae exponencialmente (o de forma oscilante)
ARMA(p,q)Decae exponencialmente después de qDecae exponencialmente después de p
Regla práctica para identificación

Si la ACF se corta abruptamente después de $q$ rezagos → probable MA(q). Si la PACF se corta después de $p$ rezagos → probable AR(p). Si ambas decaen gradualmente → probable ARMA(p,q). En la práctica esto es difícil de determinar visualmente, por eso se complementa con selección automática por criterios de información (Capítulos 8-9).
